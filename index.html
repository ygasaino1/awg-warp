WARP for AmneziaWG

Make a Cloudflare WARP profile for the AmneziaWG app. Download the .conf file here, or scan the QR code from another device.

Advanced settings

Jc, Jmin and Jmax set the junk packets AmneziaWG sends to hide the handshake. The defaults match the PowerShell script.

Use my own config as a template

Paste or load a working WARP config. The new config keeps your settings (endpoint, DNS, MTU, AmneziaWG parameters, comments). Only the private key, the address and the server key are replaced with fresh ones from Cloudflare. Your template stays in this browser.

Your QR code and config will appear here.
